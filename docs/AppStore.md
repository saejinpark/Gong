## 앱 이름 / 부제

- 이름: 공수장
- 부제 (30자): 일용직 공수 달력 · 일당 정산

## 프로모션 텍스트 (170자)

현장마다 다른 단가와 세금, 못 받은 일당까지. 달력에 공수만 찍으면 실수령액과 미입금이 한눈에 보입니다.

## 설명

공수장은 건설 현장 일용직 근로자를 위한 공수 기록 앱입니다. 복잡한 가입 없이 바로 쓰고, 기록은 내 폰에만 저장됩니다.

■ 달력에 공수 찍기
- 날짜를 누르고 1공수, 반공수, 잔업 1.5공수처럼 프리셋으로 바로 기록
- 날짜를 길게 누르면 최근 현장으로 1공수 즉시 추가
- 월~금 같은 여러 날을 한 번에 기록
- 공휴일(설·추석 연휴, 대체공휴일, 노동절, 제헌절)을 달력에 표시

■ 현장별 단가와 세금
- 현장마다 1공수 단가, 기본 식대, 세금 방식을 저장해 두면 기록할 때 자동으로 채워집니다
- 일용직 세금(하루 15만원 공제 후 2.7% + 지방소득세, 1,000원 미만 비징수), 3.3% 공제, 공제 없음 중 선택
- 식대·숙박비·교통비는 비과세 수당으로 따로 더합니다

■ 실수령액과 정산
- 이번 주, 이번 달 공수와 실수령액을 바로 확인
- 월별로 일당 합계, 수당, 세금, 실수령액, 현장별 집계, 연간 합계
- 정산 내용을 글로 만들어 카카오톡으로 반장님이나 가족에게 바로 전송
- 엑셀(CSV) 파일로 내보내기

■ 못 받은 돈 관리
- 입금되면 체크, 안 된 건 현장별로 모아서 확인
- 현장 단위로 한 번에 입금 완료 처리

■ 내 데이터는 내 폰에
- 로그인, 서버, 광고 없음
- 백업 파일을 내보내 폰을 바꿔도 그대로 복원

세금 계산은 소득세법상 일용근로소득 원천징수 방식을 따르되, 실제 공제액은 현장 사정에 따라 다를 수 있습니다. 참고용으로 활용해 주세요.

## 새로운 기능 (2.1)

- 세금 방식 선택: 일용직 세금 / 3.3% 공제 / 공제 없음 (현장별, 기록별)
- 소액부징수(1,000원 미만 비징수)와 10원 절사 반영
- 여러 날 한 번에 기록, 날짜 길게 눌러 즉시 1공수 기록
- 못 받은 돈 모아보기와 현장 단위 입금 완료 처리
- 정산 내용 공유(카톡 등), 엑셀(CSV) 내보내기
- 백업 파일 내보내기/복원
- 2026~2028년 공휴일 반영 (노동절·제헌절 포함), 공휴일 이름 표시
- 달력 글자 크기가 시스템 설정을 따르도록 개선
- iOS 17부터 지원

## 개인정보 처리방침 (게시용 문구)

공수장은 사용자의 개인정보를 수집하지 않습니다.

- 입력한 현장, 공수, 금액 정보는 사용자의 기기 안에만 저장되며 개발자나 제3자에게 전송되지 않습니다.
- 앱은 네트워크 통신, 로그인, 광고, 분석 도구를 사용하지 않습니다.
- 백업 파일은 사용자가 직접 내보낼 때만 만들어지며, 저장 위치와 공유 대상은 사용자가 정합니다.
- 앱을 삭제하면 기기 안의 모든 기록이 함께 삭제됩니다.

## 심사 메모 (Notes for Review)

이 앱은 한국 건설 일용직 근로자가 근무일(공수)과 일당을 기록하는 오프라인 가계부입니다. 로그인이 필요 없고 모든 데이터는 기기에 저장됩니다. 세금 계산은 한국 소득세법상 일용근로소득 원천징수(일 15만원 공제, 2.7%, 지방소득세 10%)를 참고용으로 보여 줍니다. 테스트 데이터가 필요하면 현장 탭에서 현장을 하나 만든 뒤 달력에서 날짜를 눌러 기록하면 됩니다.
